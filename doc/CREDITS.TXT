Doom source from here: https://github.com/id-Software/DOOM

Sample-based MUS playback and digital sound code along with tons of moral and technical support from: ChillyWilly

Generic C hashtable from here: https://github.com/dennisfrancis/generic-hashtable

LZFX codec from here: http://lzfx.googlecode.com (dead link)

screen wipe code from Chocolate Doom: https://github.com/chocolate-doom/chocolate-doom/blob/master/src/doom/f_wipe.c

more improvements and testing: thekovic, Immorpher

Music instrument set ("MIDI_Instruments", tools/gen_midi_instruments.py) is generated from "SC-55 Deemster [GZDoom].sf2", a third-party General MIDI SoundFont built from Roland SC-55 samples, sourced from the GZDoom community. See tools/soundfont/README.md.
